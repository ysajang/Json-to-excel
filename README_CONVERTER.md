# CSV ↔ JSON 변환기 (다중 파일 지원)

CSV 파일을 JSON/텍스트로, JSON 파일을 CSV로 변환하는 GUI 프로그램입니다. **여러 파일을 한 번에 일괄 변환**할 수 있습니다.

## 기능

- **다중 파일 일괄 변환**: 여러 파일을 한 번에 선택하여 일괄 변환
- **CSV → JSON**: CSV 파일을 JSON 형식으로 변환
- **CSV → 텍스트**: CSV 파일을 텍스트 형식으로 변환
- **JSON → CSV**: JSON 파일을 CSV 형식으로 변환
- **진행 상황 표시**: 프로그레스 바와 상세 로그로 변환 진행 상황 확인
- **결과 요약**: 성공/실패 개수 자동 집계
- **다양한 인코딩 지원**: UTF-8, UTF-8-sig, CP949, EUC-KR
- **커스텀 구분자**: 쉼표, 세미콜론, 탭 등
- **출력 폴더 선택**: 원본과 같은 폴더 또는 지정한 폴더에 저장

## 설치 방법

### 1. 가상환경 생성 및 활성화

```bash
# 가상환경 생성
python -m venv venv

# Windows에서 활성화
venv\Scripts\activate

# Linux/Mac에서 활성화
source venv/bin/activate
```

### 2. 의존성 설치

```bash
pip install -r requirements.txt
```

## 사용 방법

### Python으로 직접 실행

```bash
python csv_json_converter.py
```

### EXE 파일로 빌드

```bash
# EXE 빌드
python build_exe.py

# 또는 직접 pyinstaller 사용
pyinstaller --onefile --windowed --name=CSV_JSON_Converter csv_json_converter.py
```

빌드된 EXE 파일은 `dist` 폴더에 생성됩니다.

## 프로그램 사용법

1. **변환 타입 선택**: 상단 라디오 버튼에서 원하는 변환 타입 선택
2. **파일 추가**: "파일 추가" 버튼을 클릭하여 변환할 파일들을 선택 (다중 선택 가능)
   - 여러 번 클릭하여 파일을 계속 추가할 수 있습니다
   - 선택된 파일 목록이 화면에 표시됩니다
3. **파일 관리**:
   - "선택 항목 제거": 리스트에서 선택한 파일 제거
   - "전체 제거": 모든 파일 제거
4. **출력 폴더 설정**:
   - "원본 파일과 같은 폴더에 저장" 체크: 각 파일을 원본과 같은 폴더에 저장
   - 체크 해제 후 "폴더 선택": 모든 파일을 지정한 폴더에 저장
5. **옵션 설정** (CSV → JSON/텍스트만):
   - 인코딩: 파일 인코딩 선택
   - 구분자: CSV 구분자 선택 (쉼표, 세미콜론, 탭)
   - 예쁘게 출력: JSON 파일을 들여쓰기하여 저장
6. **일괄 변환**: "일괄 변환 시작" 버튼을 클릭하여 모든 파일 변환 수행
   - 진행 상황이 프로그레스 바와 로그에 표시됩니다
   - 변환 완료 후 성공/실패 개수가 요약됩니다

## 로그

모든 작업은 `logs` 폴더에 로그 파일로 저장됩니다.
로그 파일명 형식: `converter_YYYYMMDD_HHMMSS.log`

## 주의사항

- 큰 파일의 경우 변환에 시간이 걸릴 수 있습니다
- JSON → CSV 변환 시 중첩된 객체는 평탄화되지 않습니다
- CSV → JSON 변환 시 첫 번째 행이 헤더로 사용됩니다
