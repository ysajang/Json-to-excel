# 쿠팡 리뷰 수집기 - 크롬 확장 프로그램

쿠팡 상품 리뷰를 자동으로 수집하여 JSON 및 Excel 파일로 저장하는 크롬 확장 프로그램입니다.

## 설치 방법

### 1. 개발자 모드로 설치

1. Chrome 브라우저를 열고 `chrome://extensions/`로 이동
2. 우측 상단의 **"개발자 모드"** 토글 활성화
3. **"압축해제된 확장 프로그램을 로드합니다"** 클릭
4. `chrome-extension` 폴더 선택

### 2. 아이콘 추가 (선택사항)

`chrome-extension/icons` 폴더에 다음 크기의 아이콘을 추가하세요:
- `icon16.png` (16x16)
- `icon48.png` (48x48)
- `icon128.png` (128x128)

아이콘이 없어도 확장 프로그램은 작동합니다.

## 사용 방법

### 1. 쿠팡 상품 페이지 열기

쿠팡 상품 페이지를 브라우저에서 엽니다:
```
https://www.coupang.com/vp/products/상품ID
```

### 2. 확장 프로그램 실행

1. 브라우저 툴바의 확장 프로그램 아이콘 클릭
2. "쿠팡 리뷰 수집기" 선택
3. 팝업 창이 열립니다

### 3. 리뷰 수집

1. URL 입력란에 쿠팡 상품 URL 입력 (또는 현재 페이지 URL이 자동으로 입력됨)
2. **"리뷰 수집 시작"** 버튼 클릭
3. 새 탭에서 리뷰 수집이 진행됩니다

### 4. 결과 다운로드

수집이 완료되면:
- **JSON 다운로드**: JSON 형식으로 다운로드
- **Excel 다운로드**: Excel 형식으로 다운로드

## 주요 기능

- ✅ 자동 리뷰 수집
- ✅ 모든 페이지 자동 탐색
- ✅ 중복 리뷰 자동 제거
- ✅ JSON 및 Excel 형식 지원
- ✅ 실시간 진행률 표시
- ✅ 탭별 리뷰 구분 저장
- ✅ 리뷰 조회 및 검색 기능

## 파일 구조

```
chrome-extension/
├── manifest.json       # 확장 프로그램 설정
├── popup.html          # 팝업 UI
├── popup.css           # 팝업 스타일
├── popup.js            # 팝업 로직
├── content.js          # 페이지에 주입되는 스크립트
├── background.js       # 백그라운드 서비스 워커
├── collection-ui.js    # 수집 중 표시되는 UI
├── icons/              # 아이콘 파일들
└── README.md           # 상세 문서
```

## 기술 스택

- Manifest V3
- Chrome Extensions API

## 주의사항

- 쿠팡의 이용약관을 준수하여 사용하세요
- 과도한 요청은 차단될 수 있습니다
- Access Denied 발생 시 잠시 후 다시 시도하세요

## 문제 해결

### 리뷰가 수집되지 않을 때

1. 쿠팡 상품 페이지에서 실행 중인지 확인
2. 페이지가 완전히 로드될 때까지 대기
3. 브라우저 콘솔에서 로그 확인

### Excel 다운로드가 안 될 때

1. 브라우저의 다운로드 권한 확인
2. 팝업 차단 해제 확인
3. 다시 시도
