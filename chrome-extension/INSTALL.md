# 크롬 확장 프로그램 설치 가이드

## 📦 설치 방법

### 1단계: 개발자 모드 활성화

1. Chrome 브라우저를 엽니다
2. 주소창에 `chrome://extensions/` 입력 후 Enter
3. 우측 상단의 **"개발자 모드"** 토글을 **ON**으로 설정

### 2단계: 확장 프로그램 로드

1. **"압축해제된 확장 프로그램을 로드합니다"** 버튼 클릭
2. 파일 탐색기에서 `chrome-extension` 폴더 선택
3. **"폴더 선택"** 클릭

### 3단계: 확인

확장 프로그램 목록에 **"쇼핑몰 리뷰 수집기"**가 표시되면 설치 완료!

## 🚀 사용 방법

### 지원 사이트

- **쿠팡**: `https://www.coupang.com/vp/products/상품ID`
- **네이버 스마트스토어**: `https://smartstore.naver.com/스토어ID/products/상품ID`

### 방법 1: 현재 페이지에서 실행

1. 쿠팡 또는 네이버 스마트스토어 상품 페이지 열기
2. 브라우저 툴바의 확장 프로그램 아이콘 클릭
3. "쇼핑몰 리뷰 수집기" 선택
4. 팝업에서 URL이 자동 입력된 상태로 **"리뷰 수집 시작"** 클릭

### 방법 2: URL 직접 입력

1. 확장 프로그램 팝업 열기
2. URL 입력란에 쿠팡 또는 네이버 스마트스토어 상품 URL 입력
3. **"리뷰 수집 시작"** 클릭

## 📥 결과 다운로드

수집이 완료되면:

- **JSON 다운로드**: JSON 형식으로 다운로드
- **CSV로 다운 받기**: CSV 형식으로 다운로드 (Excel에서 열 수 있음)
  - 한글이 깨지지 않도록 UTF-8 BOM이 포함되어 있습니다

## ⚠️ 주의사항

- 쿠팡 또는 네이버 스마트스토어 상품 페이지에서만 작동합니다
- 페이지가 완전히 로드된 후 실행하세요
- Access Denied 발생 시 잠시 후 다시 시도하세요

## 🔧 문제 해결

### 확장 프로그램이 보이지 않을 때

1. `chrome://extensions/`에서 확장 프로그램이 활성화되어 있는지 확인
2. 브라우저를 재시작해보세요

### 리뷰가 수집되지 않을 때

1. 쿠팡 또는 네이버 스마트스토어 상품 페이지인지 확인
2. 페이지가 완전히 로드될 때까지 대기
3. URL이 `.../products/숫자` 형태인지 확인

### 다운로드가 안 될 때

1. 브라우저의 다운로드 권한 확인
2. 팝업 차단 해제 확인

## 📝 참고

- CSV 파일은 Excel에서 열면 자동으로 표 형식으로 표시됩니다
- 네이버 스마트스토어는 별점 필터 없이 전체 리뷰만 수집합니다
